01 · 系统概览

一个数据库底座，五大应用协同

系统的核心数据是「排课总台账」，排课看板与班课管理直接读写它；诊断课看板通过自动化从总台账同步、关键数据看板通过 API 从外部系统导入——五个应用共享同一套数据库。

排课总台账

系统的数据底座。每一条记录代表一次课或一个事项，包含学生、年级、日期、时段、教室、老师等完整信息。

数据层

排课看板

以「周 × 教室 × 时段」网格直观呈现课表，支持添加课程、新增事项、快速查看本周排期等。

操作视图

班课管理

聚焦长期班的生命周期管理，提供开班统计、多维筛选、一键复制与批量导入。

管理视图

数据流向

排课总台账 排课看板 · 按周网格展示 | 班课管理 · 按班课聚合

排课看板与班课管理直接读写排课总台账；此外，诊断课台账由排课总台账自动同步、班课数据台账由外部系统 API 导入，分别支撑诊断课看板与关键数据看板（详见下方架构图）。

04 · 排课看板

排课看板

以「星期 × 时段 × 教室」三维网格呈现一周排课，一眼掌握校区每日每教室的占用情况，解决教务排课上的各种痛点，在排课端解放生产力。

校区排课总览

顶部展示「本周」日期范围，并按天显示当日课程数，快速了解本周整体排课密度。

周课表网格

时间轴课表：纵轴为时间（08:00–20:00），横轴为教室1 至 教室4。每节课按开始时间自动定位到对应位置，卡片高度代表课时长短。

排课看板展示

核心操作

编辑课程

为指定教室、时段排入一节课

点击时间轴上任意位置，系统按点击时间预填开始时间，填写学生、教室、类型后保存，课程卡片即自动定位到时间轴对应刻度；点击已有卡片可再次编辑或删除。

新增事项

排入非课程性质的公共/个人事项

选择「全体事项 / 个人事项」，可排入备课、家长会、请假等非授课安排，同样按时间定位在时间轴上，一目了然。

使用流程

  1. 1

    查看本周排课

    打开看板，顶部自动定位到当前周，直观浏览每日每教室的排课密度。

  2. 2

    识别空位 / 冲突

    通过网格空白格快速发现可用时段，通过卡片颜色识别课程类型。

    3. 打开看板，选择日期后查看当天时间轴；点击轨道上对应时间排课，卡片即自动定位，调整开始 / 结束时间会实时移动。

    时间轴上的卡片位置即代表当前所处时段，沿轴浏览即可快速定位进行中的课程。

05 · 班课管理

班课管理

聚焦班课管理，提供开班导入、班课统计、多维筛选、一键复制与批量导入。

班课管理展示

核心操作

新增班课

手动创建一个长期班，填写学生、年级、日期、时段等信息，保存后进入班课列表与统计。

模板导入

适用于整班批量建课场景。一次导入多名学生的长期班排期，自动写入排课总台账。

复制课程

在课程卡片上右键，选择复制后在编辑界面确认修改并保存，即可快速生成一节相似的新课。

06 · 快速上手

三步开始排课

从零到完成第一次排课的最短路径。

第一步 · 新增一条排课记录

在排课看板点击「日历空白处」，或在班课管理点击「新增班课 / 导入长期班」。填写学生、年级、日期、时段、教室、老师等关键信息。

第二步 · 在看板核对排期

回到排课看板，确认课程卡片落在正确的「周 × 时段 × 教室」网格中。如需调整，编辑该记录的日期/时段/教室即可，网格会实时更新。

第三步 · 在班课管理跟踪状态

长期班会自动进入班课管理列表，通过筛选查看开班、授课、结课状态，统计卡片实时反映整体进度。

什么时候用 排课看板？
  • · 想直观查看某周某教室的排课
  • · 需要快速新增单次课程或事项
  • · 排查教室 / 时段冲突
什么时候用 班课管理？
  • · 统计开班 / 授课 / 结课数量
  • · 按年级、学期、状态筛选长期班
  • · 批量导入或复制相似课程
